# 流程台账附件插件下载 — FaaS 方案

> 通过 FaaS 后端调用 OpenAPI #106 提取附件，前端多选 + JSZip 批量打包下载。
> 更新：2026-07-24

---

## 一、整体架构

```
前端 HTML 插件
  │  POST + Api-Key header + credentials:'omit'
  │  {"input": {}}
  ▼
FaaS 后端 Python 插件
  │  OAuth client_credentials → Bearer token
  ▼
OpenAPI #106 → POST /openapi/thirdparty/api/workflow/v1/process/finish/page
  │  requireComments: true 才能获取评论中的文件
  ▼
返回 → 后端提取文件 → 重组为 processes[] + files[] → 回前端
```

**为什么必须走后端？** 流程台账相关 API 只有 OpenAPI 通道（`/openapi/...`），没有 Gateway 代理（`/web/gateway/...`），前端无法直接调用。纯前端受 CORS 限制。必须用 FaaS 后端做 OAuth → Bearer token 中转。

## 二、后端 Python 插件（文件提取核心）

### 2.1 OpenAPI 鉴权

```python
APP_ID = "xxx"
APP_SECRET = "xxx"
TOKEN_URL = "https://openapi.ihr360.com/openapi/oauth/token"

def _get_token() -> str:
    import urllib.request, base64
    from urllib.parse import urlencode
    auth = base64.b64encode(f"{APP_ID}:{APP_SECRET}".encode()).decode()
    body = urlencode({"grant_type": "client_credentials", "scope": "client"}).encode()
    req = urllib.request.Request(TOKEN_URL, data=body, headers={
        "Authorization": f"Basic {auth}",
        "Content-Type": "application/x-www-form-urlencoded",
    }, method="POST")
    with urllib.request.urlopen(req, timeout=15) as resp:
        import json
        data = json.loads(resp.read().decode())
        return data.get("access_token") or data["data"]["access_token"]
```

- 缓存 token 避免重复请求
- 限速 10 req/s

### 2.2 拉取已完成审批单据

```
POST https://openapi.ihr360.com/openapi/thirdparty/api/workflow/v1/process/finish/page
Authorization: Bearer {token}
Content-Type: application/json; charset=UTF-8

{
  "page": 1,
  "rows": 50,           # 最大 50
  "source": null,        # null=当前年份，可传 "2023" 跨年
  "requireComments": true,  # ❗必须 true 才返回评论中的附件
  "statuses": []          # 空=查询所有状态，也可传 ["PASS","DENIED",...]
}
```

分页从 **1 开始**，`rows` 最大 **50**。多页循环直到 `data.content` 为空或 `page >= totalPages`。

### 2.3 文件提取 — 数据来源（5 种）

| 来源 | 位置 | 触发条件 | 文件类型 |
|------|------|---------|---------|
| **1. accessoryIdList** | `formInfoList[].value` | `inheritCode == "accessoryIdList"`，value 是 URL 字符串数组 | attach |
| **2. imageIdList** | `formInfoList[].value` | `inheritCode == "imageIdList"`，value 是 URL 字符串数组 | image |
| **3. 文件对象数组** | `formInfoList[].value` | value 为对象数组，元素含 `fileId/fileName/url` 等键 | 根据 `type` 字段判断 |
| **4. 评论中的 pics** | `comments[].data.pics` | requireComments=true 时存在 | image |
| **5. 评论中的 attaches** | `comments[].data.attaches` | requireComments=true 时存在 | attach |

代码逻辑（Python）：

```python
def extract_files(processes):
    files = []
    for p in processes:
        base = dict(
            processId=str(p.get("id", "")),
            processCode=str(p.get("applicationCode") or ""),
            createTime=str(p.get("applyTime") or ""),
            applicantName=str(p.get("applicantName", "")),
            templateName=str(p.get("approvalSettingName", "")),
            title=str(p.get("respondentName", "")),
        )

        # 来源 1 & 2 & 3
        for field in (p.get("formInfoList") or []):
            code = field.get("inheritCode", "")
            val = field.get("value")
            if code == "accessoryIdList" and isinstance(val, list):
                for url in val:
                    files.append({**base, fileUrl: url, fileType: "attach", ...})
            if code == "imageIdList" and isinstance(val, list):
                for url in val:
                    files.append({**base, fileUrl: url, fileType: "image", ...})
            if isinstance(val, list):
                for obj in val:
                    if isinstance(obj, dict) and ("fileId" in obj or "fileName" in obj):
                        files.append({**base, fileUrl: obj.fileUrl, ...})

        # 来源 4 & 5
        for comment in (p.get("comments") or []):
            data = comment.get("data") or comment
            for item, ftype in [(data.get("pics"), "image"), (data.get("attaches"), "attach")]:
                for obj in (item or []):
                    files.append({**base, fileUrl: obj.fileUrl, fileType: ftype, ...})
    return files
```

### 2.4 文件名推断（三重优先级）

```python
{
    "fileType": "attach" / "image",
    "fileId": "xxx",
    "fileName": "xxx",       # 推断逻辑见下方
    "fileUrl": "https://...",
    "officeFileUrl": "https://...",
}
```

推断优先级：

1. **API 返回的 `fileName` 字段** — 最优先
2. **从 URL 末尾提取** — 正则 `/\/([^/?#]+?\.\w+)(?:$|[?#])/`
3. **按文件类型默认** — `"附件"` 或 `"图片"`（后端 fallback）

```python
def _filename_from_url(url, fallback):
    from urllib.parse import unquote, urlparse
    path = urlparse(url).path.rstrip("/")
    name = unquote(path.split("/")[-1]) if "/" in path else ""
    if name and "." in name and not name.startswith("."):
        return name
    return fallback
```

## 三、前端 FaaS 调用（获取数据）

### 3.1 调用格式

```javascript
var FAAS_URL = 'https://faasapi.ihr360.com/public/api/function/execute/v1/{functionId}/version/latest';
var FAAS_KEY = '{ApiKey}';

fetch(FAAS_URL, {
  method: 'POST',
  mode: 'cors',
  credentials: 'omit',
  headers: {
    'Content-Type': 'application/json',
    'Api-Key': FAAS_KEY,          // ❗是 "Api-Key"，不是 "x-api-key"
  },
  body: JSON.stringify({input: {}}),
})
.then(r => r.text())
.then(t => {
  var d = JSON.parse(t);
  if (d && d.data && typeof d.data === 'object' && 'code' in d.data) d = d.data;
  var data = d.data || {};
  var processes = data.processes || [];
  var files = data.files || [];
});
```

**4 个必填项（缺一不可）：**
- `credentials: 'omit'`
- `'Api-Key'` header（注意大小写）
- `body: JSON.stringify({input: {}})`
- 解 FaaS 包裹（检查 `data.data.code`）

## 四、前端批量下载（JSZip 多选打包）

### 4.1 数据模型

| 数据 | 用途 |
|------|------|
| `allProcesses[]` | 展示表格行，每行含 `hasFile`、`fileCount`、`files[]` |
| `allFiles[]` | 实际文件记录，含 `fileUrl`、`fileName`、`fileType` |

### 4.2 HTML 结构

```html
<div class="batch-bar" id="batchBar">
```

### 4.3 多选逻辑（checkbox）

```javascript
var selectedKeys = {};
function procKey(p) { return p.processId || p.title; }

cb.addEventListener('change', function() {
  if (this.checked) selectedKeys[this.getAttribute('data-key')] = 1;
  else delete selectedKeys[this.getAttribute('data-key')];
  updateBatchUI();
});

function updateBatchUI() {
  var c = Object.keys(selectedKeys).length;
  document.getElementById('selCount').textContent = c > 0 ? '已选 ' + c + ' 个流程' : '未选中流程';
  document.getElementById('batchDlBtn').disabled = c === 0;
}
```

### 4.4 批量下载核心逻辑

```javascript
document.getElementById('batchDlBtn').addEventListener('click', function(e) {
  e.preventDefault();
  var btn = document.getElementById('batchDlBtn'), prog = document.getElementById('dlProgress');

  // 1. 收集选中流程的所有文件
  var todo = [];
  allProcesses.forEach(function(p) {
    if (selectedKeys[procKey(p)]) (p.files || []).forEach(function(f) { todo.push(f); });
  });
  if (!todo.length) { prog.textContent = '所选流程无文件可下载'; return; }

  btn.disabled = 1;
  btn.textContent = '打包中...';
  var zip = new JSZip(), total = todo.length, done = 0, failed = 0, nameCount = {};

  // 2. 串行下载（递归 next）
  function next(i) {
    if (i >= total) {
      prog.textContent = '正在生成压缩包...';
      zip.generateAsync({ type: 'blob' }).then(function(blob) {
        var a = document.createElement('a');
        a.href = URL.createObjectURL(blob);
        a.download = '流程台账附件_' + new Date().toISOString().slice(0, 10) + '.zip';
        document.body.appendChild(a);
        a.click();
        document.body.removeChild(a);
        setTimeout(function() { URL.revokeObjectURL(a.href); }, 60000);
        prog.textContent = '下载完成' + (failed ? '（' + failed + '个失败）' : '');
        prog.style.color = 'var(--green-500)';
        btn.textContent = '批量下载';
        btn.disabled = 0;
      });
      return;
    }

    var f = todo[i];
    var url = f.officeFileUrl || f.fileUrl;
    if (!url) { failed++; next(i + 1); return; }

    // 3. 文件名 + 去重
    var bn = f.fileName || '文件_' + (i + 1);
    if (!bn.includes('.')) {
      var pm = url.match(/\/([^/?#]+?\.\w+)(?:$|[?#])/);
      if (pm) bn = decodeURIComponent(pm[1]);
    }
    nameCount[bn] = (nameCount[bn] || 0) + 1;
    var zn = nameCount[bn] > 1 ? bn.replace(/(\.\w+)?$/, '_' + nameCount[bn] + '$1') : bn;

    prog.textContent = '正在下载 (' + (done + failed + 1) + '/' + total + ') ' + bn;

    fetch(url, { mode: 'cors', credentials: 'omit' })
      .then(function(r) {
        if (!r.ok) throw Error('HTTP ' + r.status);
        var ct = r.headers.get('content-type') || '';
        return r.blob().then(function(b) { return { blob: b, contentType: ct }; });
      })
      .then(function(r) {
        // 4. 根据 Content-Type 推断扩展名
        if (!zn.includes('.')) {
          var extMap = {
            'image/jpeg': 'jpg', 'image/png': 'png', 'image/gif': 'gif',
            'application/pdf': 'pdf', 'application/msword': 'doc',
            'application/vnd.openxmlformats-officedocument.wordprocessingml.document': 'docx',
            'application/vnd.ms-excel': 'xls',
            'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet': 'xlsx',
            'text/plain': 'txt', 'text/html': 'html', 'text/csv': 'csv',
            'application/zip': 'zip', 'application/json': 'json',
          };
          var ext = '';
          for (var ct in extMap) {
            if (r.contentType.indexOf(ct) !== -1) { ext = extMap[ct]; break; }
          }
          if (!ext) ext = f.fileType === 'image' ? 'jpg' : 'bin';
          zn = zn + '.' + ext;
        }
        zip.file(zn, r.blob);
        done++;
        prog.textContent = '已完成 ' + done + '/' + total;
        next(i + 1);
      })
      .catch(function(e) {
        failed++;
        prog.textContent = '下载失败 ' + failed + ' 个 (' + (done + failed) + '/' + total + ')';
        next(i + 1);
      });
  }
  next(0);
});
```

### 4.5 文件名扩展名推断优先级

| 优先级 | 来源 | 示例 |
|:-----:|------|------|
| 1️⃣ | API 返回的 `fileName` | `"审批表.pdf"` |
| 2️⃣ | URL 路径提取 `/\/([^/?#]+?\.\w+)(?:$|[?#])/` | `https://.../report.docx?t=123` → `report.docx` |
| 3️⃣ | HTTP Content-Type 映射 | `application/pdf` → `.pdf` |
| 4️⃣ | 按 fileType 默认 | image → `.jpg`，其它 → `.bin` |

## 五、关键注意事项

### 5.1 后端

| 要点 | 说明 |
|------|------|
| `requireComments: true` | 必须设置，否则评论中的附件/图片不返回 |
| `statuses: []` | 空=全部状态；`["PASS"]` 只查已通过 |
| 跨年查询 | `source` 参数切换年份（"2023" 等） |
| 分页从 1 开始 | page=1 是第一页 |
| rows 最大 50 | 一次最多 50 条 |
| `applicationCode` | 审批编号的正确字段名 |

### 5.2 前端（FaaS）

| 要点 | 说明 |
|------|------|
| `Api-Key` header | 严格区分大小写 |
| `credentials: 'omit'` | 必须设置 |
| `{"input": {}}` | 请求体必须如此包裹 |
| 解 FaaS 包裹 | 检查 `data.data.code` |
| JSZip CDN | `cdnjs.cloudflare.com` 的 `jszip/3.10.1` |

### 5.3 前端（批量下载）

| 要点 | 说明 |
|------|------|
| 浏览器内存限制 | 单文件 > 50MB 或总包 > 200MB 可能失败 |
| 串行下载 | 递归 `next(i+1)`，不要并行 fetch |
| 文件名去重 | `nameCount` 字典加 `_2` `_3` 后缀 |
| CORS | 文件 URL 需允许跨域读取 |
| `officeFileUrl` > `fileUrl` | 优先用预览 URL |
| 进度反馈 | `prog.textContent` 实时显示 |

## 六、调试 Checklist

- [ ] `requireComments: true` 是否正确传入 API？
- [ ] FaaS 请求头是不是 `Api-Key`（不是 `x-api-key`）？
- [ ] FaaS 请求体是不是 `{"input": {}}`？
- [ ] `credentials: 'omit'` 有没有设？
- [ ] FaaS 返回后有没有解 `data` 包裹？
- [ ] 文件 URL 有没有跨域限制？
- [ ] 下载后文件能否正常打开？（扩展名正确？）
- [ ] 文件名有无扩展名？是否需从 URL 或 Content-Type 推断？
