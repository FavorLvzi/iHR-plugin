# 流程台账附件直链下载 — 无 FaaS 方案

> 手动生成 Bearer Token，直接调 OpenAPI #106 获取文件下载地址。
> 更新：2026-07-24

---

## 流程（仅需 3 步）

```
1. 获取 Bearer Token  →  2. 调 OpenAPI #106  →  3. 提取 fileUrl 直接下载
```

---

## Step 1：获取 Bearer Token

用 Postman / curl / Python 脚本调 OAuth 接口：

```bash
# 替换 APP_ID 和 APP_SECRET 为你自己的
APP_ID="你的APP_ID"
APP_SECRET="你的APP_SECRET"

curl -X POST "https://openapi.ihr360.com/openapi/oauth/token?grant_type=client_credentials" \
  -H "Authorization: Basic $(echo -n "$APP_ID:$APP_SECRET" | base64)" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "grant_type=client_credentials&scope=client"
```

返回示例：

```json
{
  "access_token": "eyJhbGciOiJSUzI1NiIs...",
  "token_type": "bearer",
  "expires_in": 7200,
  "scope": "client"
}
```

拿到 `access_token`，有效期 7200 秒（2 小时），过期后需重新获取。

---

## Step 2：调 OpenAPI #106 获取流程数据

```bash
TOKEN="上一步获取的access_token"

curl -X POST "https://openapi.ihr360.com/openapi/thirdparty/api/workflow/v1/process/finish/page?companyId={公司ID}" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "page": 1,
    "rows": 50,
    "requireComments": true,
    "statuses": []
  }'
```

---

## Step 3：提取文件下载地址

从响应 `data.content[]` 中提取文件的 `fileUrl`（或 `officeFileUrl`）：

| 文件位置 | 提取路径 |
|---------|---------|
| 表单附件 | `content[].formInfoList[].value` 其中 `inheritCode="accessoryIdList"` |
| 表单图片 | `content[].formInfoList[].value` 其中 `inheritCode="imageIdList"` |
| 评论附件 | `content[].comments[].data.attaches[].fileUrl` |
| 评论图片 | `content[].comments[].data.pics[].fileUrl` |

提取出的 URL 可直接在浏览器打开、用 `wget` / `curl` 下载，或分享给他人。

---

## Python 脚本示例（完整）

```python
import base64, json, urllib.request, time
from urllib.parse import urlencode

APP_ID = "你的APP_ID"
APP_SECRET = "你的APP_SECRET"
COMPANY_ID = "你的公司ID"

# 1. 获取 Token
auth = base64.b64encode(f"{APP_ID}:{APP_SECRET}".encode()).decode()
body = urlencode({"grant_type": "client_credentials", "scope": "client"}).encode()
req = urllib.request.Request(
    "https://openapi.ihr360.com/openapi/oauth/token",
    data=body,
    headers={
        "Authorization": f"Basic {auth}",
        "Content-Type": "application/x-www-form-urlencoded",
    },
)
with urllib.request.urlopen(req, timeout=15) as resp:
    token = json.loads(resp.read().decode())["access_token"]
    print(f"✓ Token 获取成功，有效期 7200s")

# 2. 调 #106 接口获取所有流程
all_files = []
page = 1
while True:
    req_body = json.dumps({
        "page": page, "rows": 50, "source": None,
        "requireComments": True, "statuses": [],
    }).encode()
    req = urllib.request.Request(
        f"https://openapi.ihr360.com/openapi/thirdparty/api/workflow/v1/process/finish/page?companyId={COMPANY_ID}",
        data=req_body,
        headers={
            "Authorization": f"Bearer {token}",
            "Content-Type": "application/json; charset=UTF-8",
        },
    )
    with urllib.request.urlopen(req, timeout=30) as resp:
        result = json.loads(resp.read().decode())

    if result.get("code") != 0:
        break

    items = result.get("data", {}).get("content") or []
    if not items:
        break

    for p in items:
        pid = p.get("id", "")
        # 从 formInfoList 提取文件 URL
        for f in (p.get("formInfoList") or []):
            code = f.get("inheritCode", "")
            val = f.get("value")
            if code == "accessoryIdList" and isinstance(val, list):
                for url in val:
                    if isinstance(url, str) and url.startswith("http"):
                        all_files.append({"processId": pid, "url": url, "type": "attach"})
            if code == "imageIdList" and isinstance(val, list):
                for url in val:
                    if isinstance(url, str) and url.startswith("http"):
                        all_files.append({"processId": pid, "url": url, "type": "image"})
            if isinstance(val, list):
                for obj in val:
                    if isinstance(obj, dict) and ("fileUrl" in obj or "url" in obj):
                        furl = obj.get("fileUrl") or obj.get("url", "")
                        if furl:
                            all_files.append({"processId": pid, "url": furl, "type": obj.get("type", "attach")})

        # 从 comments 提取
        for comment in (p.get("comments") or []):
            data = comment.get("data") or comment
            for key, ftype in [("pics", "image"), ("attaches", "attach")]:
                for obj in (data.get(key) or []):
                    furl = obj.get("fileUrl", "")
                    if furl:
                        all_files.append({"processId": pid, "url": furl, "type": ftype})

    print(f"  第 {page} 页完成，已收集 {len(all_files)} 个文件")
    page += 1

# 3. 输出结果
print(f"\n✅ 共获取 {len(all_files)} 个文件下载地址")
print("=" * 60)
for f in all_files:
    print(f"[{f['type']}] {f['url']}")

# 可选：保存到文件
with open("流程台账附件下载地址.txt", "w", encoding="utf-8") as f:
    for item in all_files:
        f.write(f"{item['url']}\n")
print(f"\n下载地址已保存到 流程台账附件下载地址.txt")
```

## 注意事项

| 要点 | 说明 |
|------|------|
| Token 有效期 | 7200 秒（2 小时），过期后需重新获取 |
| Token 不可分享 | 不要将 Token 发给他人或嵌入到 HTML/页面中 |
| 公司ID | URL 参数 `companyId` 必填，从 i人事 后台获取 |
| 跨年数据 | 如需获取往年数据，请求体中加 `"source": "2023"` 等 |
| 分页 | page=1 起始，rows ≤ 50 |
